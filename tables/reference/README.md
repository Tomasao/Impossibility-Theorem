# Original manuscript table fragments

These 11 `.tex` files are copied verbatim from table environments in the supplied version 14 article and Supplementary Document S1. They retain original captions, labels, macros, citations and cross-references. They are source fragments for use in the manuscript context, not standalone documents or independently validated claims.

Numerical data can be regenerated as CSV, Markdown and a standalone TeX/PDF document using `scripts/export_tables.py` or the root reproduction driver. The source-to-data mapping is in `docs/RESULTS_MAP.md`.
