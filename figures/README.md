# Manuscript figure sources

Figures 1–3 use TikZ/PGFPlots; Figure 4 uses NumPy, pandas and Matplotlib. Archived PDFs/PNG are included. The root driver regenerates Figure 1/3 data blocks, compiles the TeX figures with `--tex`, and renders Figure 4 with `--plots`.

See `../docs/RESULTS_MAP.md` for the exact CSV dependencies and `../REPRODUCIBILITY.md` for commands.
